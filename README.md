# riesgo-vial-peru
Proyecto Final Data Engineering - Riesgo Vial Perú
Sistema Analítico de Riesgo Vial en Perú
Descripción
Proyecto de Data Engineering orientado a identificar zonas de alto riesgo vial mediante el análisis de accidentes de tránsito.

Objetivo
Diseñar un pipeline de datos utilizando Databricks, PySpark y Power BI para apoyar la toma de decisiones sobre seguridad vial.

Tecnologías
GitHub
Python
PySpark
Databricks
SQL
Power BI
Arquitectura
Datos Públicos ↓ GitHub ↓ Bronze ↓ Silver ↓ Gold ↓ Power BI

Capas
Bronze
Datos originales sin transformación.

Silver
Datos limpios y estandarizados.

Gold
Indicadores y métricas de negocio.

KPI Principal
Índice de Riesgo Vial.
